# Поисковая система

Вариант 16:

Реализация элементов ИИ - модуль индексирования документов

Сфера применения - Сеть Интернет

Стратегия поиска - Векторная

Язык - русский

В качестве интеллектуализации модуля индексирования документов было решено использовать семантическое индексирование с использованием эмбеддингов документов и поиска по смыслу, параллельно с классический модулем индексирования документов.

В качестве реализации варианта сферы применения был выбран краулинг текстов Wikipedia с помощью библиотеки **wikipediaapi**

## Описание модулей

[crawler](crawler.py) - модуль, отвечающий за парсинг текста со статей Wikipedia. Сохраняет полученные тексты в файлы по индексу <<номер_файла>>.txt в папке docs

[preprocessor](preprocessor.py) - модуль, отвечающий за предобработку(очистку, разбиение, токенизацию, лемматизацию) текстов в папке docs и сохранение их в папку processed с таким же названием и форматом
